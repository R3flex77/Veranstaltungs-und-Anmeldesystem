# Veranstaltungs-und-Anmeldesystem
Datenbank: http://localhost:8080/
Seite : http://localhost/ 

Event Management System
Ein vollständiges Event-Management-System mit Docker, PHP und MySQL. 

Features
•	Benutzer-Authentifizierung (Login/Registrierung)
•	Rollen-System (User/Veranstalter)
•	Event-Verwaltung für Veranstalter
•	Event-Buchung für User
•	Bild-Upload für Events

Setup Anleitung
•	"docker compose up" um das Event-Management-System zu starten
